# Ступка и колба — лавка алхимика

Учебный интернет-магазин команды **workshop_vibe** для [воркшопа ИТМО](https://github.com/itmo-workshop-09-11-2026/workshop-guide): ингредиенты, зелья, свитки и артефакты. Чистый HTML, CSS и JavaScript без сборки и зависимостей; работает на GitHub Pages, с локального сервера и из распакованного ZIP.

**Публичный сайт:** https://itmo-workshop-09-11-2026.github.io/workshop_vibe/

## Что умеет

| ID | Функция | Как проверить за 30 секунд |
|---|---|---|
| Минимум | 12 товаров с названием, ценой и кнопкой «Добавить»; корзина; удаление; итог | «Перо феникса» 100 ₽ + «Флакон утренней росы» 200 ₽ = 300 ₽ → удалить перо → 200 ₽ → удалить флакон → «Корзина пуста», 0 ₽ |
| F1 | Иллюстрации с подписями и заглушкой | у каждого товара SVG и подпись; если картинка не загрузилась — круг с инициалами товара |
| F2 | Количество в корзине | «+» и «−» в строке корзины, суммы пересчитываются; «−» неактивен на 1, «+» — на остатке |
| F3 | Сохранение после перезагрузки | добавить товары, применить промокод, обновить страницу — всё на месте |
| F4 | Поиск по названию | «мед» находит «Мёд горного тролля» (регистр и ё не важны) |
| F5 | Категории и сброс | выбрать «Свитки», нажать «Сбросить» |
| F6 | Сортировка по цене | «Сначала дешевле» / «Сначала дороже» |
| F7 | Промокод 10% | `ALCHEMY10`: 300 ₽ → 270 ₽, на корзину ставится печать; повторное применение не копит скидку |
| F8 | Избранное | сердечко на карточке, вкладка «Избранное» со счётчиком |
| F9 | Телефон | ширина 360 px: плавающая кнопка корзины с суммой, корзина открывается панелью |
| F10 | Клавиатура | Tab по всем элементам, видимый фокус, Esc закрывает панель корзины, ссылка «К каталогу» |
| Q1 | Автотесты | `node --test "tests/unit/*.test.js"` — 10 тестов логики корзины, промокода, фильтров и хранения |
| D1, D2 | Деплой | GitHub Pages по HTTPS, автоматическое обновление при каждом push в `main` |
| Сверх ТЗ | | светлая и тёмная тема с переключателем, отмена удаления из корзины, остатки товаров, синхронизация корзины между вкладками |

Backend на Go (B1–B6: API каталога, серверный поиск, заказы, SQLite, остатки, защищённое изменение каталога) в разработке. Фронтенд уже умеет с ним работать: при запуске через `go run .` каталог берётся из `GET /api/products`, поиск уходит на сервер, появляется кнопка «Оформить заказ».

## Запуск

Требования: Go 1.24+ для локального сервера; Python 3 — альтернатива без Go; Node.js 22+ для тестов.

macOS / Linux:

```bash
go run .
```

Windows PowerShell:

```powershell
go run .
```

Откройте http://localhost:8000. Другой порт: `PORT=8001 go run .` (PowerShell: `$env:PORT = "8001"; go run .`).

Без Go:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

## Тесты

```bash
node --test "tests/unit/*.test.js"
```

```bash
python3 tests/smoke.py
```

## ZIP для сдачи

```bash
go run . --pack
```

Получится `shop.zip` с `index.html` в корне. Сайт работает из распакованной папки через любой HTTP-сервер и даже двойным кликом по `index.html`.

## Как устроено

```text
site/
  index.html          разметка и шаблоны карточки, строки корзины, тоста
  styles.css          дизайн-система: токены, светлая и тёмная темы, адаптив
  app.js              рендер и обработчики событий
  js/config.js        ключи localStorage, промокоды, лимиты
  js/catalog.js       каталог из 12 товаров (его же читает Go-сервер)
  js/core.js          чистые функции: цены, поиск, сортировка, корзина, скидка
  js/store.js         состояние, сохранение в localStorage, синхронизация вкладок, заказ
  js/api.js           клиент API Go-сервера с автоопределением режима
  js/ui/theme.js      применение сохранённой темы до первой отрисовки
  assets/             логотип, иллюстрации товаров, шрифты
tests/unit/           unit-тесты на node:test
docs/CONTRACT.md      контракт архитектуры для команды агентов
```

Корзина хранится в `localStorage` под ключами `workshop_vibe:cart:v1`, `workshop_vibe:favorites:v1`, `workshop_vibe:promo:v1`, `workshop_vibe:theme:v1` — сайты одной GitHub-организации делят хранилище, поэтому ключи с префиксом репозитория.

## Команда

Команда workshop_vibe: три разработчика и четыре AI-агента (Claude Code и Codex) работают параллельно по общему контракту [`docs/CONTRACT.md`](docs/CONTRACT.md) и правилам [`AGENTS.md`](AGENTS.md). Роли и процесс — в [`.team/PLAYBOOK.md`](.team/PLAYBOOK.md).

## Известные ограничения

- Оформление заказа доступно только при запуске с Go-сервером; на GitHub Pages и из ZIP работает офлайн-каталог.
- Товары, цены и иллюстрации вымышленные, оплата не принимается.
