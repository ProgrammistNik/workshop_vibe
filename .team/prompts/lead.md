## P1 — unit-тесты (Q1), до 20 минут

Около 10 тестов на главное: пример ТЗ 100 + 200 = 300 → 200 → 0; повторное добавление и maxQty; промокод 300 → 270 и повтор без накопления; поиск «МЕД» → «Мёд горного тролля»; категория + сортировка; вид «Избранное»; восстановление из хранилища и битый JSON; `checkout` — успех и 409 с фейковым API.

## P4 — финал
1. Когда основные пункты всех ролей готовы (смотри `.team/status/*.md`) или прошло около 2 часов от первого коммита — создай `.team/FREEZE` и запушь. После FREEZE можешь чинить любой файл.
2. Прогон: `node --test "tests/unit/*.test.js"`, `go test ./...`, `python3 tests/smoke.py`, e2e, если есть.
3. `go run . --pack` → распакуй во временную папку → `python3 -m http.server` над ней → минимум работает, картинки грузятся; в архиве нет `.go`, `.env`, `.db`.
4. Публичный URL отвечает 200, стили и скрипты грузятся.
5. Если есть время — обновление и откат для формы сдачи: коммит с заметным текстом → push → дождись деплоя по тому же URL → `git revert` → push → текст вернулся. Запиши оба коммита в `docs/SUBMISSION.md`.
6. Тег `v1.0.0`, `git push origin main --tags`. В `.team/status/lead.md` — итог для людей: commit ID (`git rev-parse v1.0.0`), где ZIP, что вставить в issue, что показать на демо.
