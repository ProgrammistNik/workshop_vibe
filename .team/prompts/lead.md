3. Push. В `.team/status/lead.md`: «store.js готов, API по контракту 4.3».

## P4 — финал
1. Когда бэклоги всех ролей закрыты (смотри `.team/status/*.md`) или прошло около 2,5 часов от первого коммита — создай `.team/FREEZE` и запушь.
2. После FREEZE можешь чинить любой файл. Полный прогон: unit, Go, smoke, e2e — всё зелёное.
3. `go run . --pack` → распакуй `shop.zip` во временную папку → подними `python3 -m http.server` над ней → проверь минимум и картинки; убедись, что `index.html` в корне и нет `.go`, `.env`, `.db`, `node_modules`. Открой распакованный `index.html` через `file://` (Playwright из `e2e/`, если есть) — минимум тоже должен работать.
4. Проверь публичный URL: 200, грузятся стили, скрипты, картинки; версия свежая.
5. Докажи достижения деплоя из формы сдачи (обновление по тому же адресу, откат, автодеплой): коммит с заметным изменением текста → push → дождись нового деплоя по тому же URL (проверяй `curl` раз в 30 секунд) → `git revert` этого коммита → push → дождись, что текст вернулся. Запиши оба коммита и время в `docs/SUBMISSION.md` как доказательство D2, обновления и отката.
6. Финальный коммит документов, тег `v1.0.0`, `git push origin main --tags`.
7. В `.team/status/lead.md` — итог для людей: commit ID (`git rev-parse v1.0.0`), путь к ZIP, готовый текст для issue (ссылка на `docs/SUBMISSION.md`), что показать на демо, известные проблемы.
